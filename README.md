# 宇宙银行今日营业

这是独立分享的静态网页源码。只包含运行所需的页面、样式、随机方案与动效代码，无应用账号或业务后端。

运行：在本目录执行 `python3 -m http.server 4173 --bind 127.0.0.1 --directory dist`，访问 `http://127.0.0.1:4173/`。

示例请使用“我正在给月球图书馆添一架望远镜”、3000元和2元预算，全部为虚构。输入与号码仅在当前页面内存中，刷新后清空；复制与分享由使用者主动触发。仅供成年人娱乐，随机号码不预测结果、不保证收益，不包含购买或支付功能。

本分享版本移除了原应用的第三方角色图及用户提供的音乐，改为文字柜员和静音。未携带 Git 元数据、私有历史、测试、部署配置、旧素材或原项目说明。官方规则链接保留作出处，不是应用请求接口；规则与税务估算可能变化，使用前应再次核对。当前未附加开源许可证。
